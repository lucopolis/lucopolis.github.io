# Be Center — website

Static site (originally built with Lovable), migrated off Hostinger for full ownership/control.

## Updating the "monthly course" banner

The banner that appears between the hero and "Para quem" sections is driven
entirely by one file:

```
content/monthly-course.json
```

Edit the values there (title, description, button text/link, etc.) whenever
a new course/turma opens for enrollment. Set `"enabled": false` to hide the
banner entirely. No code changes needed — just edit that file and
save/commit/push.

The banner's look (colors, spacing, font) lives in `assets/monthly-feature.css`,
and the logic that inserts it into the page lives in `assets/monthly-feature.js`.
You shouldn't need to touch either of those for routine monthly updates.

## Swapping images

Each image used on the site is a plain file under `assets/` (e.g.
`assets/team-hero-x6xa0ADG.jpg`). To swap an image, replace that file's
contents while keeping the exact same filename — no code editing required.
If you want to rename a file or add a brand-new image, ask Claude to help,
since the filename is also referenced inside the built app code.

## About the rest of the site

The core site (hero, "Para quem", services, courses, team, testimonials) is
a compiled/minified React app (`assets/index-*.js` and `assets/index-*.css`)
originally generated by Lovable. It is not meant to be hand-edited. For
bigger structural or design changes, the best path is editing the original
Lovable project (or its synced source) and re-exporting/re-deploying, rather
than hand-editing the minified bundle.
